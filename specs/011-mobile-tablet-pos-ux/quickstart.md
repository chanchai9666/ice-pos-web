# Quickstart & Verification Guide: Mobile & Tablet POS Usability and Login Alignment

**Feature Branch**: `011-mobile-tablet-pos-ux`
**Date**: 2026-10-25

## 1. Prerequisites
- Node.js >= 18.x
- Dependencies installed (`npm install`)
- Dev server running (`npm run dev`)

## 2. Test & Verification Scenarios

### Scenario 1: ตรวจสอบความสูงหน้า Login (Login Height Alignment)
1. เปิดบราวเซอร์ไปที่หน้า `http://localhost:3000/login`
2. สังเกตขนาดความสูงของการ์ดในโหมดเริ่มต้น "รหัส PIN แคชเชียร์"
3. คลิกแท็บ "ชื่อผู้ใช้ / รหัสผ่าน"
4. **เกณฑ์ที่ต้องผ่าน**:
   - การ์ดเข้าสู่ระบบคงความสูงเดิม ไม่หดสั้นหรือยุบตัววูบวาบ
   - ช่องกรอก Username, Password และปุ่มเข้าสู่ระบบจัดอยู่กึ่งกลางแนวตั้งอย่างสวยงาม
   - ความสูงของช่อง Input และปุ่มกดไม่ต่ำกว่า 48px

### Scenario 2: ตรวจสอบการใช้งานบนมือถือ/แท็บเล็ต (Mobile & Tablet POS Usability)
1. เปิดเครื่องมือ Developer Tools ของบราวเซอร์ (กด F12 หรือ Cmd+Option+I)
2. ปรับขนาดหน้าจอจำลองเป็นอุปกรณ์พกพา เช่น **iPad Air (820x1180)** หรือ **iPhone 14 Pro (393x852)**
3. เข้าสู่ระบบไปยังหน้าจุดขาย `/pos`
4. **เกณฑ์ที่ต้องผ่าน**:
   - หน้าจอแคตตาล็อกสินค้าแสดงผลเต็มความกว้างอย่างสวยงาม ไม่บีบอัด
   - แถบเมนูด้านล่าง (Global App Bottom Navigation) แสดงผลชิดขอบล่างของหน้าจอ
   - เมื่อกดเลือกสินค้า 1-2 ชิ้น แถบสรุปยอดเงินและปุ่มตะกร้าจะปรากฏขึ้นอย่างชัดเจน
   - เมื่อแตะที่แถบสรุปตะกร้า ลิ้นชัก `PosCartBottomSheet` จะเลื่อนขึ้นมาแสดงรายการสินค้า ปุ่มปรับเพิ่ม/ลดจำนวน และปุ่มชำระเงิน
   - แตะปุ่มชำระเงิน จะเปิดหน้าต่าง `PosCheckoutModal` เพื่อรับเงินสด/โอนเงินได้ตามปกติใน 1 สัมผัส

### Scenario 3: ตรวจสอบการกลับสู่โหมด Desktop เมื่อขยายหน้าจอ
1. ขยายขนาดหน้าจอกลับมาเกิน 1024px (เช่น 1440x900)
2. **เกณฑ์ที่ต้องผ่าน**:
   - แถบเมนูด้านล่าง (Bottom Nav) และปุ่มสรุปตะกร้าลอยจะซ่อนไปโดยอัตโนมัติ
   - เลย์เอาต์กลับมาเป็น 2 คอลัมน์ (ซ้ายแคตตาล็อก 60% / ขวาพาเนลตะกร้า 40%) และ Sidebar แสดงผลตามปกติ
