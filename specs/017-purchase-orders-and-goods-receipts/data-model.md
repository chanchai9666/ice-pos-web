## 4. Lifecycle & State Transitions

### 4.1 Purchase Order Lifecycle
```text
[ DRAFT ] ──────────> [ ORDERED ] ──────────> [ PARTIALLY_RECEIVED ] ──────────> [ COMPLETED ]
   │                       │                             │
   └──> [ CANCELLED ]      └──> [ CANCELLED ]            └──> [ COMPLETED (Force Close) ]
```

- **DRAFT → ORDERED**: เมื่อผู้ใช้กด "ยืนยันการสั่งซื้อ (`POST /confirm`)"
- **DRAFT / ORDERED → CANCELLED**: เมื่อผู้ใช้กดยกเลิก (`POST /cancel`)
- **ORDERED → PARTIALLY_RECEIVED**: อัตโนมัติเมื่อมีการยืนยันใบตรวจรับสินค้าบางรายการ
- **PARTIALLY_RECEIVED → COMPLETED**: อัตโนมัติเมื่อยอดตรวจรับครบทุกรายการ หรือกดบังคับปิด (`POST /close`)

### 4.2 Goods Receipt Lifecycle
```text
[ DRAFT ] ──────────> [ COMPLETED ] (สต็อกสินค้าสาขาอัปเดตเพิ่มทันที)
   │
   └──> [ CANCELLED ]
```
