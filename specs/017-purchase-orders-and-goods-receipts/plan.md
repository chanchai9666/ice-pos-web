# Implementation Plan: ระบบใบสั่งซื้อสินค้าและตรวจรับสินค้าเข้าคลัง (Purchase Orders & Goods Receipts)

**Branch**: `017-purchase-orders-and-goods-receipts` | **Date**: 2026-10-27 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/017-purchase-orders-and-goods-receipts/spec.md`

## Summary

พัฒนาระบบออกใบสั่งซื้อสินค้า (Purchase Orders - PO) และระบบตรวจรับสินค้าเข้าคลัง (Goods Receipts - GR) บน Web Frontend เชื่อมต่อกับ Backend API กลุ่ม `04.2`, `04.3` และ `04.1` อย่างครบวงจร โดยออกแบบเป็นแท็บการทำงานรวมอยู่ในหน้า `/inventory` รองรับการแปลงหน่วยเงิน Satang to THB, การสแกนบาร์โค้ดตรวจรับด้วยกล้อง, การแจ้งเตือนรับสินค้าเกินยอดสั่งซื้อ (Over-delivery Warning), และมี Loading Overlay บล็อกการกดซ้ำตามธรรมนูญระบบ

## Technical Context

**Language/Version**: TypeScript 5.x, Node.js 18+  
**Primary Dependencies**: Next.js 16.4.2 (App Router), React 19.3.0, TailwindCSS v4, Lucide React, `@zxing/library` & `@zxing/browser` (Barcode Scanning)  
**Storage**: Web Storage (Tokens in localStorage), Backend REST APIs  
**Testing**: Vitest / React Testing Library, Manual Scenario Validation  
**Target Platform**: Responsive Web App (Desktop, Tablet, Mobile POS)  
**Project Type**: Web Application Frontend  
**Performance Goals**: หน้าจอเรนเดอร์ใน < 100ms, โหลดข้อมูล API และแสดงผลตารางใน < 500ms  
**Constraints**: ขนาดปุ่มสัมผัส ≥ 48x48px (Elderly-Friendly), สีและตัวอักษร Contrast สูง (WCAG 2.1 AA), แสดง Full Loading Overlay ทุกครั้งที่มีการเรียก API (ธรรมนูญข้อ 6.6), ภาษาไทยเป็นหลัก  
**Scale/Scope**: จัดการเอกสาร PO และ GR ในแต่ละสาขา รองรับรายการสินค้าหลายร้อยรายการพร้อม Pagination
