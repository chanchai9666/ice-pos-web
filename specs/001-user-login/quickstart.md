## 1. ข้อกำหนดเบื้องต้นและการเตรียมความพร้อม (Prerequisites)

1. Node.js (เวอร์ชัน 20+) และ npm ติดตั้งพร้อมในระบบ
2. เซิร์ฟเวอร์ ICE POS Backend API กำลังทำงานที่ `http://127.0.0.1:8080`
   - ทดสอบความพร้อม: `curl http://127.0.0.1:8080/api/v1/health` (ต้องได้รับสถานะ OK)
   - ตรวจสอบรายการสาขา: `curl http://127.0.0.1:8080/api/v1/branches`
3. บัญชีผู้ใช้สำหรับการทดสอบ:
   - ผู้ดูแลระบบ/ผู้จัดการ: Username และ Password ที่กำหนดไว้
   - พนักงานแคชเชียร์: PIN 4-8 หลักที่ผูกกับสาขาในระบบ

---

## 2. ขั้นตอนการรันระบบเพื่อทดสอบ (Start Development Server)

```bash
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:3000/login` (หรือ `http://localhost:3000`)

## 3. สถานการณ์ทดสอบเพื่อยืนยันความถูกต้อง (Validation Scenarios)

### สถานการณ์ที่ 1: การเปิดหน้าจอครั้งแรกและการเลือกโหมดเริ่มต้น
- **ขั้นตอน**:
  1. ล้างข้อมูลใน `localStorage` หรือเปิดแท็บไม่ระบุตัวตน (Incognito)
  2. เข้าสู่ระบบหน้า `http://localhost:3000/login`
- **ผลลัพธ์ที่คาดหวัง**:
  - หน้าจอแสดงผลในโหมด "เข้าใช้งานด้วย PIN" เป็นค่าเริ่มต้น (ตาม FR-002)
  - รายการสาขาถูกดึงมาแสดงผล และหากมีสาขาเดียวจะเลือกสาขานั้นเป็นค่าเริ่มต้นอัตโนมัติ
  - ปรากฏแผงแป้นตัวเลขเสมือน (Virtual Numpad 0-9) ชัดเจน

### สถานการณ์ที่ 2: การเข้าใช้งานด่วนด้วย PIN (Cashier Quick Login)
- **ขั้นตอน**:
  1. เลือกสาขาที่ปฏิบัติงาน
  2. กดป้อนรหัส PIN ผ่านแผงตัวเลขบนหน้าจอ หรือพิมพ์ผ่านคีย์บอร์ดจริง
  3. กดยืนยันเข้าสู่ระบบ
- **ผลลัพธ์ที่คาดหวัง**:
  - หน้าจอขึ้นสถานะ Loading ป้องกันการกดซ้ำ
  - ระบบตรวจสอบ PIN และนำทางไปยังหน้าขายสินค้า (POS Terminal) ทันที (ตาม FR-011)
  - Token และข้อมูลสาขาถูกบันทึกใน `localStorage`

### สถานการณ์ที่ 3: การสลับโหมดและเข้าสู่ระบบด้วย Username & Password
- **ขั้นตอน**:
  1. กดปุ่มสลับไปยังโหมด "ชื่อผู้ใช้ / รหัสผ่าน"
  2. กรอก Username และ Password ที่ถูกต้อง
  3. ทดสอบกดปุ่มรูปดวงตา (Show/Hide Password) เพื่อสลับการแสดงผลรหัสผ่าน
  4. กดปุ่ม "เข้าสู่ระบบ"
- **ผลลัพธ์ที่คาดหวัง**:
  - เข้าสู่ระบบสำเร็จและนำทางไปยังหน้าจอหลักตามสิทธิ์ของผู้ใช้งาน

### สถานการณ์ที่ 4: การจัดการข้อผิดพลาดและ Cooldown เมื่อป้อนผิด 5 ครั้ง
- **ขั้นตอน**:
  1. ป้อนรหัส PIN หรือรหัสผ่านที่ไม่ถูกต้อง 5 ครั้งติดต่อกัน
- **ผลลัพธ์ที่คาดหวัง**:
  - ครั้งที่ 1-4: ระบบแสดงข้อความแจ้งเตือนสีแดงภาษาไทยว่ารหัสไม่ถูกต้อง พร้อมล้างช่องกรอก
  - ครั้งที่ 5: ระบบระงับการลองทันที แสดงตัวเลขนับถอยหลัง 60 วินาที (Cooldown Timer) และปิดปุ่มกดทั้งหมด (ตาม FR-012)
  - เมื่อครบ 60 วินาที: ปุ่มกดกลับมาใช้งานได้ตามปกติ
