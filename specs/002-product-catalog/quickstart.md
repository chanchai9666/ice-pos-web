# Quickstart Validation Guide: ระบบเมนูหลักและการจัดการสินค้าและหมวดหมู่ (Product Catalog)

**Feature**: `002-product-catalog`  
**Date**: 2026-10-21  

---

## 1. ข้อกำหนดเบื้องต้น (Prerequisites)

1. Backend API รันอยู่ที่ `http://127.0.0.1:8080` (ตรวจสอบผ่าน `GET http://127.0.0.1:8080/api/v1/health`)
2. Frontend พัฒนาด้วย Next.js 16+ รันบนพอร์ต 3000 (`npm run dev`)
3. มีบัญชีผู้ใช้งานสำหรับทดสอบ:
   - ผู้ดูแลระบบ / ผู้จัดการ: บทบาท `ADMIN` หรือ `MANAGER`
   - พนักงานแคชเชียร์: บทบาท `CASHIER`

---

## 2. ขั้นตอนการทดสอบการทำงานตั้งแต่ต้นจนจบ (Validation Scenarios)

### Scenario 1: การแสดงผลเมนูระบบหลัก และการพับเก็บ Sidebar (FR-001, FR-002)
1. เข้าสู่ระบบด้วยบัญชีผู้จัดการ (`ADMIN` / `MANAGER`)
2. ตรวจสอบว่าหน้าจอแสดง App Shell:
   - แถบ Sidebar ด้านข้างแสดงรายการเมนูหลัก (หน้าขาย POS, แคตตาล็อกสินค้า, สต็อก ฯลฯ)
   - แถบ Header แสดงชื่อผู้ใช้, สาขาปัจจุบัน, และปุ่มออกจากระบบ
3. คลิกปุ่มพับเก็บเมนู (Collapse Sidebar) บน Desktop หรือสลับหน้าจอเป็นขนาดแท็บเล็ต
4. **ผลลัพธ์ที่คาดหวัง**: แถบเมนูย่อเก็บได้อย่างราบรื่น และขยายออกได้โดยไม่เกิด Layout Shift

### Scenario 2: การตรวจสอบสิทธิ์การเข้าถึงเมนูตามบทบาท (Role Protection) (FR-001a)
1. เข้าสู่ระบบด้วยบทบาท `CASHIER` (ผ่าน Username หรือ Quick PIN)
2. ตรวจสอบแถบ Sidebar:
   - ต้อง **ไม่ปรากฏ** เมนู "จัดการสินค้าและหมวดหมู่"
3. ทดสอบพิมพ์ URL `/catalog` หรือ `/products` โดยตรงใน Address Bar
4. **ผลลัพธ์ที่คาดหวัง**: ระบบนำทางกลับไปยังหน้าขาย `/pos` อัตโนมัติ พร้อมแสดงข้อความเตือนว่าไม่มีสิทธิ์เข้าถึงหน้านี้

### Scenario 3: การเปิดดูรายการสินค้า การค้นหา และการกรองข้อมูล (FR-004, FR-005, FR-006)
1. เข้าสู่ระบบด้วยบัญชี `ADMIN` และคลิกเมนู "จัดการสินค้าและหมวดหมู่"
2. หน้าจอโหลดตารางสินค้า แสดงรูปภาพ, SKU, Barcode, ชื่อ, หมวดหมู่, ราคา (หน่วยบาท), สถานะ
3. พิมพ์คำค้นหาในช่องค้นหา (เช่น "น้ำแข็ง")
4. **ผลลัพธ์ที่คาดหวัง**: ตารางอัปเดตแสดงเฉพาะรายการที่ตรงกับคำค้นหาทันที
5. เลือกตัวกรองหมวดหมู่ และตัวกรองสถานะ (เปิด/ปิดใช้งาน)
6. **ผลลัพธ์ที่คาดหวัง**: รายการสินค้ากรองตรงตามเงื่อนไขที่เลือก

### Scenario 4: การสร้างสินค้าใหม่ และการสร้างบาร์โค้ดภายใน (FR-008, FR-009, FR-010)
1. ในแท็บ "รายการสินค้า" คลิกปุ่ม "+ เพิ่มสินค้าใหม่"
2. แถบเลื่อนด้านข้าง (Slide-over Drawer) เปิดขึ้นมา
3. กรอกข้อมูล:
   - ชื่อสินค้า: "น้ำแข็งถ้วยพร้อมดื่ม 200g"
   - SKU: "ICE-CUP-200"
   - หมวดหมู่: เลือกจาก Dropdown (ดึงมาจาก API)
   - หน่วยนับ: "ถ้วย" (UOM)
   - ราคาขาย: "15.00" (บาท)
   - ต้นทุน: "7.50" (บาท)
4. คลิกปุ่ม "สร้างบาร์โค้ดอัตโนมัติ" ในช่อง Barcode
   - ระบบสร้างรหัสบาร์โค้ดภายในร้านแสดงในช่อง
5. เลือกอัปโหลดรูปภาพสินค้า (แสดงภาพ Preview ตัวอย่าง)
6. คลิกปุ่ม "บันทึกข้อมูล"
7. **ผลลัพธ์ที่คาดหวัง**: Drawer ปิดลง, มีแจ้งเตือนสีเขียวบันทึกสำเร็จ, สินค้าใหม่ปรากฏบนแถวแรกของตารางทันที

### Scenario 5: การจัดการหมวดหมู่สินค้า (FR-013, FR-014)
1. สลับไปที่แท็บ "หมวดหมู่สินค้า" (Categories Tab)
2. คลิกปุ่ม "+ เพิ่มหมวดหมู่" (Modal Dialog เปิดขึ้น)
3. กรอกชื่อหมวดหมู่ "น้ำแข็งเกล็ดพิเศษ" และระบุลำดับแสดงผล
4. คลิกบันทึก
5. **ผลลัพธ์ที่คาดหวัง**: หมวดหมู่ใหม่ถูกบันทึกและแสดงในตารางหมวดหมู่ทันที

### Scenario 6: การลบสินค้าอย่างปลอดภัย (Safe Deletion) (FR-012)
1. คลิกปุ่มลบสินค้าในตาราง
2. ปรากฏกล่องข้อความยืนยันความปลอดภัย
3. หากสินค้ามีประวัติการขาย ระบบแจ้งเตือนให้สลับเป็น "ปิดการใช้งาน" แทนการลบ
4. **ผลลัพธ์ที่คาดหวัง**: ไม่เกิดข้อผิดพลาดรุนแรง และข้อมูลประวัติการขายยังคงสมบูรณ์

### Scenario 7: การทดสอบ UX/UI และการป้อนข้อมูลสำหรับผู้สูงอายุบนจอสัมผัส (Elderly-Friendly & Touchscreen) (FR-017 ถึง FR-021, SC-007 ถึง SC-010)
1. ตรวจสอบหน้าจอแคตตาล็อกสินค้าและแถบเมนูบนหน้าจอสัมผัสหรือโหมด Device Emulation (Tablet / Touch):
   - ตรวจวัดขนาดปุ่มกด เมนู แท็บ ช่องอินพุต และปุ่มการกระทำในตาราง ต้องมีขนาดพื้นที่สัมผัสไม่ต่ำกว่า 48x48px และมีระยะห่างกดง่าย ไม่ติดชิดกันเกินไป
2. ตรวจสอบขนาดตัวอักษรและคอนทราสต์:
   - ตัวอักษรเนื้อหาทั่วไปมีขนาดไม่เล็กกว่า 16px (1rem), ตัวเลขราคาและหัวข้อสำคัญมีขนาดใหญ่และหนาเด่นชัด
   - คอนทราสต์ของข้อความและพื้นหลังผ่านเกณฑ์ WCAG 2.1 AA (>= 4.5:1) ไม่ใช้สีเทาจาง
3. เปิดแบบฟอร์มเพิ่ม/แก้ไขสินค้า และแตะที่ช่องป้อน "ราคาขาย" หรือ "ต้นทุน":
   - ปรากฏแป้นพิมพ์ตัวเลขสัมผัสเสมือนขนาดใหญ่ (Virtual Numeric Keypad)
   - แตะปุ่มตัวเลขขนาดใหญ่เพื่อกรอกราคา
   - ทดสอบแตะปุ่มลบ (Backspace) และปุ่มล้างค่า (Clear) เพื่อแก้ไขค่าตัวเลข
4. ตรวจสอบการตอบสนองทันที (Immediate Feedback):
   - ทุกปุ่มมีการเปลี่ยนสีหรือแสดง Active State ทันทีเมื่อสัมผัส
5. ทดสอบกดยืนยันการลบสินค้า:
   - กล่องยืนยันความปลอดภัย (Confirmation Dialog) แสดงผลขนาดใหญ่ พร้อมปุ่มยืนยันและยกเลิกที่มีสีแตกต่างกันอย่างเด่นชัด และข้อความภาษาไทยตรงไปตรงมา
6. **ผลลัพธ์ที่คาดหวัง**: ผู้ใช้งานทุกช่วงวัยและผู้สูงอายุสามารถมองเห็น สัมผัส และป้อนข้อมูลได้อย่างถูกต้อง แม่นยำ และปลอดภัย
