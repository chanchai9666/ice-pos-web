# Quickstart & Verification Guide: POS Product Stock Level & Border Status Alerts

**Feature**: `007-pos-product-stock-alerts`  
**Date**: 2026-10-24  
**Status**: Ready for Verification

## 1. ข้อกำหนดเบื้องต้นและการเตรียมระบบ (Prerequisites & Setup)

1. ตรวจสอบว่าระบบรันอยู่ในเครื่องหรือโหมด Development:
   ```bash
   npm run dev
   ```
2. เปิดเบราว์เซอร์และเข้าสู่หน้าจอ POS: `http://localhost:3000/pos`
3. เปิดกะการขาย (Open Shift) ให้เรียบร้อยเพื่อเข้าสู่หน้าจอการขายหน้าร้าน

## 2. ขั้นตอนการทดสอบฟังก์ชัน (Validation Scenarios)

### Scenario 1: การแสดงจำนวนสต็อกสำหรับสินค้าที่ไม่ใช่ชั่งขายทุกรายการ
- **การทดสอบ**: ดูการ์ดสินค้าทั้งหมดบนกริด เช่น "มาม่าช้างน้อย", "Default Sell UOM Product", "Ice Bag", "Pentest Soda"
- **ผลลัพธ์ที่ถูกต้อง**:
  - ทุกการ์ดต้องแสดงตัวเลขสต็อกคงเหลือชัดเจน เช่น "คงเหลือ: 10 ชิ้น" หรือ "สินค้าหมด"
  - ไม่มีการ์ดใดที่ละเว้นหรือปล่อยว่างไม่มีตัวเลขสต็อก
  - สินค้าชั่งขาย (เช่น "น้ำแข็ง") แสดงป้าย "ชั่งขาย" และข้อความ "สินค้าชั่งขาย"

### Scenario 2: การแสดงขอบสีส้มสำหรับสินค้าใกล้หมด (Low Stock)
- **การทดสอบ**: ตรวจสอบสินค้าที่มีสต็อก `> 0` แต่น้อยกว่าหรือเท่ากับ `minStock` (หรือ `<= 5` ชิ้น)
- **ผลลัพธ์ที่ถูกต้อง**:
  - การ์ดสินค้าแสดงเส้นขอบ **สีส้ม** (`border-amber-500`) ชัดเจน
  - มุมซ้ายบนแสดงป้ายสีส้ม เช่น "ใกล้หมด: 3"
  - ข้อความใต้รหัสสินค้าแสดงตัวอักษรสีส้ม/เหลืองเด่นชัด

### Scenario 3: การแสดงขอบสีแดงสำหรับสินค้าหมดสต็อก (Out of Stock)
- **การทดสอบ**: ตรวจสอบสินค้าที่มีสต็อก `<= 0` หรือยังไม่มีการรับสต็อกเข้าสาขา
- **ผลลัพธ์ที่ถูกต้อง**:
  - การ์ดสินค้าแสดงเส้นขอบ **สีแดง** (`border-rose-500`) หนา 2px มองเห็นได้ชัดเจน
  - มุมซ้ายบนแสดงป้ายสีแดง "สินค้าหมด"
  - ข้อความระบุสถานะ "สินค้าหมด (คงเหลือ 0 ชิ้น)" สีแดงชัดเจน

### Scenario 4: พฤติกรรมเมื่อกดเลือกสินค้าที่หมดสต็อก
- **การทดสอบ**: แคชเชียร์แตะเลือกการ์ดสินค้าที่มีขอบสีแดง
- **ผลลัพธ์ที่ถูกต้อง**:
  - สินค้าถูกเพิ่มลงในรายการตะกร้าสินค้าตามปกติ (ไม่ถูกบล็อกการขาย)
  - มีข้อความแจ้งเตือน Toast ปรากฏขึ้นแจ้งว่า "สินค้าหมดสต็อก: สินค้า [ชื่อ] มีสต็อกในระบบเป็น 0 (อนุญาตให้ขายต่อได้)"

### Scenario 5: สินค้าชั่งขาย (Weight-Based Product)
- **การทดสอบ**: ดูการ์ดสินค้าน้ำแข็งหรือสินค้าที่มี `productType === 'BY_WEIGHT'`
- **ผลลัพธ์ที่ถูกต้อง**:
  - แสดงป้ายสีเหลืองทอง "ชั่งขาย" พร้อมไอคอนตาชั่ง
  - ไม่แสดงขอบสีแดงหรือสีส้มตามจำนวนชิ้น
