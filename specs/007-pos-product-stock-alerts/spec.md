# Feature Specification: การแสดงจำนวนสินค้าคงเหลือและการแจ้งเตือนขอบสีสต็อกบนการ์ดสินค้า POS (POS Product Stock Level & Border Status Alerts)

**Feature Branch**: `007-pos-product-stock-alerts`

**Created**: 2026-10-24

**Status**: Draft

**Input**: User description: "-สินค้าที่ไม่ใช่แบบชั่งขาย ให้แสดงจำนวนสินค้าคงเหลือ\n-หากสินค้าใกล้หมดให้แสดงขอบส้ม หากหมดแล้วแสดงขอบแดง"

## Clarifications

### Session 2026-10-24

- Q: ระบบควรกำหนดเกณฑ์จำนวนสต็อกคงเหลืออย่างไร สำหรับการแสดงขอบสีส้ม (สินค้าใกล้หมด)? → A: ใช้ค่า `minStockLevel` ของสินค้าแต่ละรายการ (หากสินค้ารายการใดไม่ได้ระบุ ให้ใช้ค่าเริ่มต้นคงเหลือ <= 5 ชิ้น)
- Q: เมื่อแคชเชียร์กดเลือกการ์ดสินค้าที่สินค้าหมดแล้ว (ขอบสีแดง) ระบบควรมีพฤติกรรมอย่างไร? → A: อนุญาตให้เพิ่มลงตะกร้าได้ตามปกติ แต่ให้แสดงข้อความเตือน (Toast Notification) แจ้งว่าสินค้าหมดแล้ว เพื่อให้การขายหน้าร้านมีความคล่องตัวและไม่สะดุด

## User Scenarios & Testing *(mandatory)*

### User Story 1 - การแสดงจำนวนสินค้าคงเหลือสำหรับสินค้าที่ไม่ใช่ชั่งขาย (Remaining Stock Display for Non-Weight-Based Products) (Priority: P1)

แคชเชียร์สามารถตรวจสอบจำนวนสินค้าคงเหลือของสินค้าแต่ละรายการบนการ์ดสินค้าในหน้าจอ POS ได้อย่างชัดเจนและครบถ้วน โดยสินค้าทุกรายการที่ไม่ใช่แบบชั่งขาย (สินค้าขายตามหน่วยนับ/ชิ้น) จะต้องแสดงตัวเลขสต็อกคงเหลือพร้อมหน่วยนับเสมอ (เช่น "คงเหลือ: 15 ชิ้น" หรือ "คงเหลือ: 0 ซอง") แม้ว่าสต็อกในสาขาจะเป็น 0 หรือยังไม่มีประวัติการรับเข้า เพื่อให้แคชเชียร์ทราบสถานะสินค้าพร้อมขายได้ทันที โดยไม่มีการ์ดสินค้าใดที่ตกหล่นหรือไม่แสดงข้อมูลคงเหลือ ส่วนสินค้าแบบชั่งขายยังคงแสดงป้าย "ชั่งขาย" อย่างชัดเจนตามเดิม

**Why this priority**: การแสดงจำนวนสินค้าคงเหลือที่ครบถ้วนทุกรายการช่วยลดความสับสนของแคชเชียร์ ป้องกันการขายสินค้าเกินสต็อก และเพิ่มความมั่นใจในการให้บริการลูกค้าหน้าร้าน

**Independent Test**: เข้าสู่หน้าจอขาย POS ในสาขาใดก็ได้ แล้วตรวจสอบการ์ดสินค้าทั้งหมด: สินค้าที่ไม่ใช่แบบชั่งขายทุกชิ้นต้องมีข้อความระบุจำนวนคงเหลือพร้อมหน่วยนับแสดงอยู่อย่างชัดเจน และสินค้าชั่งขายแสดงป้าย "ชั่งขาย"

**Acceptance Scenarios**:

1. **Given** แคชเชียร์อยู่ที่หน้าจอ POS, **When** ดูการ์ดสินค้าที่ไม่ใช่แบบชั่งขาย (ขายตามหน่วยนับ), **Then** การ์ดแสดงป้ายและข้อความจำนวนคงเหลือ เช่น "คงเหลือ: 15 ชิ้น" หรือ "คงเหลือ 15 ชิ้น" ด้วยตัวอักษรที่อ่านง่าย ชัดเจน
2. **Given** มีสินค้าที่ยังไม่มีบันทึกยอดสต็อกในสาขา หรือยอดสต็อกเป็น 0, **When** แสดงผลบนการ์ดสินค้า, **Then** ระบบแสดงยอดคงเหลือเป็น "คงเหลือ: 0 [หน่วยนับ]" หรือสถานะ "สินค้าหมด" อย่างชัดเจน ไม่ปล่อยว่างหรือซ่อนข้อความคงเหลือ
3. **Given** สินค้าเป็นประเภทชั่งขาย (ขายตามน้ำหนัก), **When** แสดงผลบนการ์ดสินค้า, **Then** ระบบแสดงป้ายและสัญลักษณ์ "ชั่งขาย" แทนการแสดงจำนวนชิ้น

### User Story 2 - การแจ้งเตือนด้วยขอบสีส้มสำหรับสินค้าใกล้หมด และขอบสีแดงสำหรับสินค้าหมด (Orange & Red Border Alerts for Low and Out of Stock) (Priority: P1)

แคชเชียร์สามารถมองเห็นและแยกแยะสถานะความพร้อมของสต็อกสินค้าได้อย่างรวดเร็วผ่านสีของเส้นขอบการ์ดสินค้า (Border Status Color):
- **สินค้าใกล้หมด (Low Stock)**: การ์ดสินค้าแสดง **ขอบสีส้ม** (Orange Border) พร้อมป้ายเตือน เพื่อให้แคชเชียร์ทราบล่วงหน้าว่าสินค้าเหลือน้อยและควรเตรียมเติมสินค้า
- **สินค้าหมดแล้ว (Out of Stock, สต็อก <= 0)**: การ์ดสินค้าแสดง **ขอบสีแดง** (Red Border) พร้อมป้ายเตือน "สินค้าหมด" อย่างเด่นชัด ป้องกันการหยิบหรือคิดเงินผิดพลาด
- **สินค้าที่มีสต็อกปกติ (In Stock)**: แสดงเส้นขอบตามธีมปกติของระบบ ไม่แสดงสีเตือนที่รบกวนสายตา

**Why this priority**: การใช้สัญญาณขอบสีช่วยให้แคชเชียร์กวาดสายตาเพียงเสี้ยววินาทีก็ทราบระดับสต็อกได้ทันที ช่วยลดข้อผิดพลาดในการขายสินค้าที่หมดแล้ว และช่วยให้ร้านค้าบริหารจัดการสต็อกหน้าร้านได้อย่างมีประสิทธิภาพ สอดคล้องกับเกณฑ์ Elderly-Friendly

**Independent Test**: ตรวจสอบการ์ดสินค้าในหน้า POS ที่มีระดับสต็อกต่างกัน: สินค้าปกติแสดงขอบปกติ, สินค้าใกล้หมดแสดงขอบสีส้มชัดเจน, และสินค้าที่สต็อก 0 แสดงขอบสีแดงเด่นชัด

**Acceptance Scenarios**:

1. **Given** สินค้ามีสต็อกคงเหลืออยู่ในเกณฑ์สินค้าใกล้หมด, **When** การ์ดสินค้าแสดงผลบนหน้าจอ POS, **Then** เส้นขอบของการ์ดสินค้าแสดงเป็นสีส้มสว่างเด่นชัด (High Contrast Orange) ที่มองเห็นได้ชัดเจนบนธีมมืด (Dark Theme)
2. **Given** สินค้ามีสต็อกคงเหลือเท่ากับ 0 หรือติดลบ, **When** การ์ดสินค้าแสดงผลบนหน้าจอ POS, **Then** เส้นขอบของการ์ดสินค้าแสดงเป็นสีแดงชัดเจน (High Contrast Red) พร้อมป้ายข้อความ "สินค้าหมด"
3. **Given** สินค้ามีสต็อกคงเหลือมากกว่าเกณฑ์สินค้าใกล้หมด (สต็อกปกติ), **When** การ์ดสินค้าแสดงผลบนหน้าจอ POS, **Then** เส้นขอบของการ์ดแสดงสีกรมท่า/เทาเข้มตามธีมปกติของการ์ด
4. **Given** แคชเชียร์นำเคอร์เซอร์ไปชี้ (Hover) หรือสัมผัสการ์ดสินค้าที่มีขอบสีส้มหรือขอบสีแดง, **When** อยู่ในสถานะ Active/Hover, **Then** สไตล์ขอบสียังคงเน้นสีสถานะเตือนได้อย่างชัดเจน ไม่ถูกกลืนด้วยสีโฟกัสทั่วไป

### User Story 3 - การตอบสนองเมื่อแคชเชียร์เลือกสินค้าที่มีการแจ้งเตือนสต็อก (Interaction Handling for Stock-Alerted Products) (Priority: P2)

เมื่อแคชเชียร์กดเลือกการ์ดสินค้าที่มีการแจ้งเตือนสต็อก ระบบมีพฤติกรรมการตอบสนองที่ชัดเจน ป้องกันการขายสินค้าที่ไม่พร้อมจำหน่าย หรือแจ้งเตือนความรับรู้ของแคชเชียร์อย่างเหมาะสม

**Why this priority**: ป้องกันปัญหาการตัดสต็อกติดลบโดยไม่ตั้งใจ และให้ข้อมูลย้อนกลับทันที (Immediate Feedback) แก่ผู้ปฏิบัติงาน

**Independent Test**: แตะเลือกสินค้าที่มีขอบสีส้ม (ใกล้หมด) และสินค้าที่มีขอบสีแดง (หมดสต็อก) เพื่อตรวจสอบพฤติกรรมการตอบสนองและการแจ้งเตือน

**Acceptance Scenarios**:

1. **Given** แคชเชียร์แตะเลือกสินค้าที่มีขอบสีส้ม (ใกล้หมด), **When** สินค้าถูกเพิ่มลงในตะกร้า, **Then** ระบบเพิ่มสินค้าลงตะกร้าตามปกติ พร้อมอาจแสดงการแจ้งเตือนจำนวนคงเหลือที่เหลืออยู่
2. **Given** แคชเชียร์แตะเลือกสินค้าที่มีขอบสีแดง (สินค้าหมด), **When** มีการกดเลือก, **Then** ระบบเพิ่มสินค้าลงในตะกร้าได้ตามปกติ พร้อมแสดงการแจ้งเตือน (Toast Notification) แจ้งเตือนว่าสินค้ารายการนี้หมดสต็อกแล้ว เพื่อให้การขายหน้าร้านดำเนินต่อไปได้อย่างต่อเนื่อง

---

### Edge Cases

- **กรณีระบบไม่สามารถเชื่อมต่อข้อมูลสต็อกของสาขาได้ (Network Offline หรือ API Timeout)**: การ์ดสินค้าต้องแสดงสถานะสำรอง เช่น แสดงตัวเลข 0 หรือ "คงเหลือ: -" โดยไม่ให้หน้าจอค้างหรือแอปพลิเคชันหยุดทำงาน
- **กรณีสินค้าแบบชั่งขาย (BY_WEIGHT)**: สินค้าประเภทนี้คิดราคาตามน้ำหนักจากการชั่งจริง การ์ดจะแสดงป้าย "ชั่งขาย" และไม่ใช้เกณฑ์ขอบส้ม/ขอบแดงตามจำนวนชิ้น เว้นแต่จะมีการระบุนโยบายสต็อกน้ำหนักโดยเฉพาะ
- **กรณีสินค้าขายตามหน่วยมีสต็อกติดลบ (เช่น สต็อกเป็น -1 หรือ -2 จากการปรับยอดผิดพลาด)**: ระบบต้องจัดให้อยู่ในกลุ่ม "สินค้าหมด" และแสดงขอบสีแดงอย่างถูกต้อง
- **การมองเห็นสีของผู้ใช้งาน (Color Accessibility)**: สัญญาณแจ้งเตือนต้องไม่พึ่งพาเพียงสีของขอบอย่างเดียว แต่ต้องมีป้ายข้อความ (Badge/Text) และระดับความคมชัด (Contrast Ratio >= 4.5:1) ตามเกณฑ์ WCAG 2.1 AA เพื่อรองรับผู้สูงอายุและผู้ที่มีความบกพร่องในการแยกแยะสี

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ระบบต้องแสดงจำนวนสินค้าคงเหลือบนการ์ดสินค้าในหน้าจอ POS สำหรับสินค้าทุกรายการที่ไม่ใช่สินค้าแบบชั่งขาย
- **FR-002**: ในกรณีที่สินค้าที่ไม่ใช่แบบชั่งขายยังไม่มียอดสต็อกบันทึกในสาขาปัจจุบัน ระบบต้องกำหนดค่าเริ่มต้นเป็น 0 และแสดงยอดคงเหลือ 0 ชิ้น โดยไม่ละเว้นการแสดงผล
- **FR-003**: สำหรับสินค้าแบบชั่งขาย (BY_WEIGHT) ระบบต้องแสดงป้ายกำกับ "ชั่งขาย" พร้อมสัญลักษณ์ตาชั่งอย่างชัดเจนแทนการแสดงจำนวนคงเหลือ
- **FR-004**: การ์ดสินค้าที่มีระดับสต็อกคงเหลืออยู่ในเกณฑ์ "สินค้าใกล้หมด" ต้องแสดงเส้นขอบการ์ดเป็น **สีส้ม** เด่นชัด
- **FR-005**: การ์ดสินค้าที่มีระดับสต็อกคงเหลือเท่ากับ 0 หรือติดลบ (สินค้าหมด) ต้องแสดงเส้นขอบการ์ดเป็น **สีแดง** เด่นชัด พร้อมป้ายระบุ "สินค้าหมด"
- **FR-006**: ระบบต้องกำหนดเกณฑ์สินค้าใกล้หมด (Low Stock) สำหรับแสดงเส้นขอบสีส้ม โดยใช้ค่า `minStockLevel` ของสินค้าแต่ละรายการ (หากสินค้ารายการใดไม่ได้ระบุค่า minStockLevel ให้ใช้ค่าเริ่มต้นคือสต็อกคงเหลือ <= 5 ชิ้น)
- **FR-007**: เมื่อแคชเชียร์กดเลือกการ์ดสินค้าที่หมดสต็อก (ขอบสีแดง) ระบบต้องอนุญาตให้เพิ่มสินค้าลงในตะกร้าได้ตามปกติ พร้อมแสดงการแจ้งเตือน (Toast Notification) แจ้งว่าสินค้ารายการนี้หมดสต็อกแล้ว เพื่อให้การขายหน้าร้านมีความคล่องตัวและไม่สะดุด
- **FR-008**: ขอบสีส้มและสีแดงต้องมีความหนาอย่างน้อย 2px และมีค่าสีที่คอนทราสต์ชัดเจนบนพื้นหลังหน้าจอ POS ตามมาตรฐาน Elderly-Friendly

### Key Entities *(include if feature involves data)*

- **Stock Level Status**: สถานะระดับสต็อกของสินค้าในสาขาปัจจุบัน แบ่งออกเป็น:
  - `IN_STOCK`: สินค้ามีสต็อกปกติ (มากกว่าเกณฑ์ใกล้หมด) -> ขอบปกติ
  - `LOW_STOCK`: สินค้าใกล้หมด (มากกว่า 0 แต่น้อยกว่าหรือเท่ากับเกณฑ์ใกล้หมด) -> ขอบสีส้ม
  - `OUT_OF_STOCK`: สินค้าหมด (สต็อกเท่ากับ 0 หรือน้อยกว่า 0) -> ขอบสีแดง
- **Product Card Stock Display**: ข้อมูลการแสดงผลบนการ์ดสินค้า ประกอบด้วย ป้ายสถานะ (Badge), ข้อความระบุจำนวนคงเหลือพร้อมหน่วยนับ, และสีของเส้นขอบการ์ด (Border Alert Color)

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% ของการ์ดสินค้าที่ไม่ใช่แบบชั่งขาย แสดงจำนวนสินค้าคงเหลือพร้อมหน่วยนับอย่างชัดเจน
- **SC-002**: แคชเชียร์สามารถสังเกตและแยกแยะสถานะสินค้าใกล้หมด (ขอบส้ม) และสินค้าหมด (ขอบแดง) ได้อย่างถูกต้องภายในเวลาไม่เกิน 0.5 วินาที
- **SC-003**: เส้นขอบสีส้มและสีแดงมีความคมชัดผ่านเกณฑ์ WCAG 2.1 AA สามารถมองเห็นได้อย่างชัดเจนจากระยะห่างสายตาปกติ (อย่างน้อย 60 ซม.)
- **SC-004**: ป้องกันการขายสินค้าผิดพลาดหรือขายสินค้าที่หมดสต็อกหน้าร้านได้แม่นยำขึ้น 100% ตามนโยบายที่เลือกไว้

## Assumptions

- ข้อมูลระดับสต็อกคงเหลืออ้างอิงจากสาขาปัจจุบัน (Active Branch) ที่แคชเชียร์กำลังเปิดกะทำงาน
- สินค้าประเภท `BY_WEIGHT` (ชั่งขาย) ยังคงยึดการแสดงผลป้าย "ชั่งขาย" และไม่มีการแสดงขอบสีเตือนสต็อกแบบชิ้น
- เกณฑ์ขอบสีส้มและสีแดงมีผลกับการ์ดสินค้าในกริดสินค้าของหน้าจอ POS ทุกหมวดหมู่
- ขนาดเส้นขอบและความเข้มของสีถูกปรับแต่งให้เหมาะสมกับจอสัมผัส POS และสภาพแสงในร้านค้า
