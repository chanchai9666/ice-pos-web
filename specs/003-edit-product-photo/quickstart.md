# Quickstart Validation Guide: การทดสอบฟีเจอร์แก้ไขรูปสินค้าด้วยกล้องและการแสดงผลทันที

**Feature**: `003-edit-product-photo`
**Date**: 2026-10-21
**Status**: Completed

## 1. การเตรียมสภาพแวดล้อม (Prerequisites & Setup)

1. รันเซิร์ฟเวอร์สำหรับทดสอบในโหมดพัฒนา:
   ```bash
   npm run dev
   ```
2. เปิดเบราว์เซอร์เข้าสู่ระบบที่:
   `http://localhost:3000/login`
3. เข้าสู่ระบบด้วย PIN แคชเชียร์/ผู้ดูแลระบบ จากนั้นไปยังหน้าแคตตาล็อกสินค้า:
   `http://localhost:3000/catalog`

---

## 2. ขั้นตอนการทดสอบแบบ End-to-End (Validation Scenarios)

### สถานการณ์ที่ 1: ถ่ายภาพสินค้าด้วยกล้องโดยตรงและบันทึก
1. ในหน้าตารางสินค้า คลิกปุ่ม "แก้ไข" (ไอคอนดินสอ) ที่แถวของสินค้าใดสินค้าหนึ่ง
2. ในหน้าต่างแก้ไขข้อมูลสินค้า ให้สังเกตส่วน "รูปภาพสินค้า" จะพบปุ่ม:
   - "ถ่ายภาพด้วยกล้อง" (ไอคอนกล้องถ่ายรูป)
   - "เลือกไฟล์ภาพ" (ไอคอนอัปโหลด)
3. คลิกปุ่ม **"ถ่ายภาพด้วยกล้อง"**:
   - ระบบจะเปิดหน้าต่างโมดอลกล้อง (Camera Viewfinder)
   - หากเบราว์เซอร์ถามสิทธิ์ ให้กด "อนุญาต (Allow)"
   - สังเกตภาพสดจากกล้องปรากฏอย่างลื่นไหล
4. คลิกปุ่มชัตเตอร์ขนาดใหญ่ ($\ge 64$px):
   - หน้าจอจะหยุดและแสดงภาพนิ่งที่เพิ่งจับภาพได้
   - แสดงปุ่ม "ถ่ายใหม่" และ "ใช้ภาพนี้"
5. คลิก **"ใช้ภาพนี้"**:
   - หน้าต่างกล้องปิดลง และภาพที่ถ่ายจะมาแสดงเป็นภาพตัวอย่างในแบบฟอร์มสินค้า
6. คลิกปุ่ม **"บันทึกการแก้ไข"**:
   - หน้าต่างแก้ไขปิดลง และมี Toast แจ้งเตือนความสำเร็จ

### สถานการณ์ที่ 2: ตรวจสอบการแสดงผลในหน้าตารางรายการสินค้าทันที (Instant Display)
1. สังเกตแถวของสินค้าที่เพิ่งแก้ไขในตารางรายการสินค้า:
   - **ผลที่คาดหวัง**: รูปภาพสินค้าในช่องรูปภาพ (Thumbnail) เปลี่ยนเป็นรูปภาพใหม่ที่เพิ่งถ่ายทันที!
   - **ไม่ต้องกดปุ่ม F5 หรือรีเฟรชหน้าเว็บ**
   - เลขหน้า (Pagination) และตัวกรองหมวดหมู่หรือคำค้นหาไม่หลุดหรือถูกรีเซ็ต

### สถานการณ์ที่ 3: ทดสอบการสลับกล้องและกรณีปฏิเสธสิทธิ์
1. เปิดหน้าต่างกล้องอีกครั้ง
2. หากใช้อุปกรณ์ที่มีกล้องหน้า/กล้องหลัง ให้คลิกปุ่ม **"สลับกล้อง"** -> ภาพจะสลับมุมมองอย่างราบรื่น
3. ทดสอบในแท็บไม่ระบุตัวตน (Incognito) โดยกดปฏิเสธสิทธิ์กล้อง (Block):
   - ระบบต้องไม่ Crash แต่แสดงข้อความแนะนำภาษาไทยที่ชัดเจน และยังสามารถกด "เลือกไฟล์รูปภาพ" จากเครื่องได้ตามปกติ
