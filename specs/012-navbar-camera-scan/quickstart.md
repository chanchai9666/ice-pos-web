# Phase 1: Quickstart & Validation Guide

**Feature**: ปุ่มสแกนสินค้าด้วยกล้องบน Navbar (Navbar Camera Product Scanner Button)  
**Branch**: `012-navbar-camera-scan`  
**Date**: 2026-10-26  

---

## 1. Prerequisites & Setup

1. สลับมาที่กิ่งฟีเจอร์:
   ```bash
   git checkout 012-navbar-camera-scan
   ```
2. รันระบบสำหรับทดสอบ:
   ```bash
   npm run dev
   ```
3. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` และเข้าสู่ระบบในฐานะพนักงานหรือแคชเชียร์

---

## 2. Test Scenarios

### Scenario 1: ทดสอบปุ่มสแกนบน Desktop (AppHeader)
1. ขยายหน้าจอให้มีความกว้าง >= 1024px
2. ตรวจสอบที่แถบด้านบน (`AppHeader`) ทางฝั่งขวา
3. ยืนยันว่าพบปุ่ม "สแกนสินค้า" พร้อมไอคอนกล้อง ขนาดสัมผัสไม่ต่ำกว่า 48px
4. เมื่อคลิกปุ่มขณะอยู่ที่หน้า `/pos` (และเปิดกะขายแล้ว):
   - หน้าต่าง `PosCameraScannerModal` เปิดขึ้นมาพร้อมภาพจากกล้อง
5. เมื่อคลิกปุ่มขณะอยู่ที่หน้าอื่น (เช่น `/catalog`):
   - ระบบนำทางกลับมาที่ `/pos` และเปิดหน้าต่างกล้องสแกนอัตโนมัติ

### Scenario 2: ทดสอบปุ่มสแกนบน Mobile / Tablet (AppBottomNav)
1. ปรับขนาดหน้าจอผ่าน Responsive DevTools ให้มีขนาดหน้าจอมือถือ (เช่น iPhone 14 Pro หรือ iPad 768px)
2. ตรวจสอบแถบด้านล่าง (`AppBottomNav`)
3. ยืนยันว่าพบปุ่ม "สแกน" พร้อมไอคอนกล้อง ขนาดปุ่ม >= 48x48px และมีสีสันเด่นชัด
4. เมื่อแตะปุ่มสแกน:
   - ตรวจสอบว่าระบบเปิดหน้าต่างกล้องสแกนขึ้นมาทันที

### Scenario 3: ตรวจสอบกรณีที่ยังไม่ได้เปิดกะการขาย
1. ปิดกะการขายหรือเข้าสู่ระบบโดยยังไม่เปิดกะ
2. กดปุ่มสแกนบน Navbar
3. ยืนยันว่าระบบแสดงหน้าต่างแจ้งเตือนให้เปิดกะการขาย (`PosOpenShiftModal`) แทน เพื่อป้องกันข้อผิดพลาดทางบัญชี
