# Quickstart Validation Guide: ตรวจสอบระบบสแกนบาร์โค้ดผ่านกล้องและตัวนับจำนวน

**Feature Branch**: `013-barcode-scan-fix-and-counters`  
**Date**: 2026-10-26  

คู่มือทดสอบและตรวจสอบการทำงานของระบบสแกนบาร์โค้ดและตัวนับจำนวนหลังการติดตั้ง

---

## 1. การติดตั้งไลบรารีและตรวจสอบระบบ (Prerequisites)

```bash
# ตรวจสอบการติดตั้งแพ็กเกจถอดรหัสบาร์โค้ด
npm install @zxing/library @zxing/browser

# ตรวจสอบ Type check และ Lint
npx tsc --noEmit
npm run lint
```

---

## 2. ขั้นตอนการทดสอบตาม Scenario (End-to-End Validation)

### Scenario A: การทดสอบตรวจจับบาร์โค้ดข้ามเบราว์เซอร์ (Safari & Chrome)
1. เปิดหน้าขาย POS (`/pos`) บน Safari (iOS หรือ macOS) หรือ Chrome
2. กดปุ่มไอคอนกล้องสแกนที่ Navbar หรือ Bottom Nav
3. อนุญาตการเข้าถึงกล้อง (Camera Permission)
4. ส่องบาร์โค้ดสินค้าจริง (เช่น EAN-13 บนขวดน้ำ/ขนม)
5. **ผลที่คาดหวัง**:
   - ระบบอ่านรหัสได้สำเร็จภายใน 1.5 วินาที
   - กล้องไม่ค้าง และไม่มีข้อผิดพลาด unsupported engine

### Scenario B: การทดสอบตัวนับจำนวนและสัญญาณตอบรับ
1. ส่องบาร์โค้ดสินค้าที่มีอยู่ในระบบ 2 ชิ้น
   - **ผลที่คาดหวัง**: 
     - ได้ยินเสียง Beep สั้นความถี่สูง (880Hz)
     - ตัวเลขในกล่องเขียว "สแกนสำเร็จ" เพิ่มเป็น 1 และ 2 ตามลำดับ
     - แถบสถานะแสดงชื่อสินค้าที่เพิ่งสแกน
     - รายการสินค้าเพิ่มเข้าสู่ตะกร้าบิลขาย
2. ส่องบาร์โค้ดที่ไม่มีในระบบ (หรือพิมพ์รหัสทดสอบ เช่น `9999999999` ในช่องกรอกมือ)
   - **ผลที่คาดหวัง**:
     - ได้ยินเสียง Buzzer เตือนความถี่ต่ำ (160Hz)
     - ตัวเลขในกล่องแดง "ไม่พบสินค้า" เพิ่มเป็น 1
     - แถบเตือนสีแดงแสดงข้อความ "ไม่พบข้อมูลสินค้าสำหรับรหัส: 9999999999"
     - กล้องยังคงเปิดสแกนต่อเนื่องโดยไม่ต้องกดปุ่มปิดกล่องเตือน

### Scenario C: การปิดและคืนทรัพยากรกล้อง
1. กดปุ่ม "เสร็จสิ้น / ปิดหน้าต่าง"
2. **ผลที่คาดหวัง**:
   - หน้าต่าง Modal ปิดลงทันที
   - ไฟกล้องหรือการเข้าถึงกล้องดับลงทันที
   - เมื่อเปิดกล้องใหม่อีกครั้งในบิลใหม่ ตัวนับสแกนสำเร็จและไม่สำเร็จถูกรีเซ็ตเป็น 0
