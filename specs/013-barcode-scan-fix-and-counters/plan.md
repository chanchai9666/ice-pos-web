# Implementation Plan: แก้ไขระบบสแกนบาร์โค้ดผ่านกล้องและเพิ่มตัวนับจำนวนสแกนสำเร็จ/ไม่สำเร็จ

**Branch**: `013-barcode-scan-fix-and-counters` | **Date**: 2026-10-26 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/013-barcode-scan-fix-and-counters/spec.md`

## Summary

แก้ปัญหาระบบสแกนบาร์โค้ดผ่านกล้องไม่ทำงานบนเบราว์เซอร์ที่ไม่มี Native BarcodeDetector (เช่น Safari บน iOS/macOS) โดยปรับใช้ Hybrid Barcode Decoding Engine ระหว่าง Native `window.BarcodeDetector` และ `@zxing/browser` (`BrowserMultiFormatReader`) พร้อมทั้งเพิ่มระบบตัวนับจำนวนสินค้า "สแกนสำเร็จ" และ "ไม่พบสินค้า" ในรูปแบบการ์ดสรุป 2 ช่องคู่กันบนหน้าต่างสแกน พร้อมสัญญาณเสียง Beep (ความถี่สูง) / Buzzer (ความถี่ต่ำ) และรองรับการสแกนต่อเนื่อง (Continuous Scanning) เมื่อไม่พบสินค้าตามมาตรฐาน Elderly-Friendly

## Technical Context

**Language/Version**: TypeScript 5, Next.js 16.4.2 (App Router), React 19.3.0  
**Primary Dependencies**: `@zxing/library` (v0.23.0), `@zxing/browser` (v0.2.1), Tailwind CSS v4, Web Audio API  
**Storage**: Local State (Component State) สำหรับตัวนับต่อรอบสแกน, REST API / Local catalog สำหรับค้นหาสินค้า  
**Testing**: Manual E2E Validation via `quickstart.md`, Static Type Checking (`tsc`), ESLint  
**Target Platform**: Mobile (iOS Safari, Android Chrome), Tablet / iPad POS, Desktop Browsers (Chrome, Safari, Firefox, Edge)  
**Project Type**: Next.js Web Application (Frontend POS)  
**Performance Goals**: ตรวจจับบาร์โค้ดได้ภายใน <= 1.5 วินาที, เฟรมเรตวิดีโอไม่ต่ำกว่า 24 fps, การตอบสนองเสียงและสีภายใน <= 300ms  
**Constraints**: ทำงานได้สมบูรณ์แม้อุปกรณ์ไม่มี Native BarcodeDetector, ไม่พึ่งพาไฟล์เสียงภายนอก (.mp3) โดยสังเคราะห์เสียงผ่าน Web Audio API, ตัวหนังสือและการ์ดผ่านมาตรฐาน Elderly-Friendly (WCAG AA)  
**Scale/Scope**: 1 Modal Component (`PosCameraScannerModal.tsx`), 1 Main Page integration (`src/app/(main)/pos/page.tsx`)
