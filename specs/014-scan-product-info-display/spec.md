**Created**: 2026-10-26

**Status**: Draft

- Q: เมื่อสแกนบาร์โค้ดผ่านเครื่องยิงฮาร์ดแวร์บนหน้าจอขาย POS (แสดงผลผ่านกล่อง Toast) ต้องการให้แสดงราคาด้วยหรือไม่? → A: แสดงราคาด้วย โดยในข้อความ Toast ให้แสดงชื่อสินค้าพร้อมราคา เช่น "ชื่อสินค้า (฿XX.XX)" เพื่อให้ข้อมูลตรงกันทุกช่องทาง

## User Scenarios & Testing *(mandatory)*

### User Story 1 - แสดงข้อมูลสินค้าครบถ้วนเมื่อสแกนพบ (เลขบาร์โค้ด, ชื่อสินค้า, ราคา) (Priority: P1)

ในฐานะแคชเชียร์ เมื่อฉันสแกนบาร์โค้ดสินค้าที่กล้องและพบสินค้าในระบบ ฉันต้องการเห็นข้อมูลผลการสแกนล่าสุดบนหน้าต่างสแกนทันที ได้แก่ เลขบาร์โค้ด, ชื่อสินค้า และราคาขายต่อหน่วยที่แสดงเป็น Badge เด่นชัด เพื่อให้ฉันสามารถยืนยันความถูกต้องของสินค้าและราคาที่คิดเงินได้อย่างรวดเร็วโดยไม่ต้องสลับสายตาไปดูรายการในบิล

**Why this priority**: เป็นคุณค่าหลักตามความต้องการของผู้ใช้ ช่วยให้การคิดเงินมีความมั่นใจและลดข้อผิดพลาดในการขาย

**Independent Test**: เปิดหน้าต่างกล้องสแกน แล้วส่องบาร์โค้ดสินค้าที่มีในระบบ ตรวจสอบว่าแถบผลการสแกนล่าสุดแสดงเลขบาร์โค้ด ชื่อสินค้า และ Badge ป้ายราคา (เช่น `฿35.00`) อย่างครบถ้วนและชัดเจน

**Acceptance Scenarios**:

1. **Given** แคชเชียร์เปิดหน้าต่างกล้องสแกน, **When** สแกนบาร์โค้ดสินค้าที่มีอยู่ในระบบสำเร็จ, **Then** แถบผลลัพธ์แสดงสถานะสำเร็จ (สีเขียว), แสดงชื่อสินค้า, เลขบาร์โค้ด และ Badge ป้ายราคาขายต่อหน่วย (เช่น `฿35.00`)
2. **Given** แคชเชียร์พิมพ์รหัสบาร์โค้ดในช่องกรอกด้วยตนเองและกดตกลง, **When** พบสินค้าในระบบ, **Then** แถบผลลัพธ์แสดงข้อมูลชื่อสินค้า เลขบาร์โค้ด และ Badge ป้ายราคาขาย เช่นเดียวกับการสแกนผ่านกล้อง
3. **Given** แคชเชียร์ยิงบาร์โค้ดด้วยเครื่องสแกนฮาร์ดแวร์บนหน้าจอขาย POS, **When** พบสินค้าในระบบ, **Then** กล่องข้อความ Toast แสดงชื่อสินค้าพร้อมราคา เช่น "น้ำแข็งหลอดเล็ก (฿35.00)"

### User Story 2 - แสดงเฉพาะเลขบาร์โค้ดเมื่อสแกนไม่พบสินค้าในระบบ (Priority: P1)

ในฐานะแคชเชียร์ เมื่อฉันสแกนบาร์โค้ดแล้วระบบไม่พบข้อมูลสินค้า ฉันต้องการให้หน้าต่างสแกนแสดงเฉพาะเลขบาร์โค้ดที่ตรวจพบ พร้อมข้อความระบุว่าไม่พบสินค้าในระบบ โดยไม่แสดงข้อมูลชื่อหรือราคา เพื่อให้ฉันทราบรหัสที่ผิดพลาดและแยกสินค้านั้นออกจากตะกร้าได้อย่างถูกต้อง

**Why this priority**: ป้องกันความสับสนเมื่อสแกนสินค้าที่ยังไม่ได้ลงทะเบียนในระบบ และช่วยให้แคชเชียร์จดจำหรือรายงานเลขบาร์โค้ดที่ขาดหายไปได้ทันที

**Independent Test**: สแกนบาร์โค้ดที่ไม่มีในระบบ ตรวจสอบว่าแถบผลการสแกนล่าสุดแสดงสถานะเตือนสีแดง/ส้ม พร้อมเลขบาร์โค้ด และไม่มีการแสดงชื่อสินค้าหรือราคา

**Acceptance Scenarios**:

1. **Given** หน้าต่างกล้องสแกนเปิดอยู่, **When** สแกนบาร์โค้ดที่ไม่มีในฐานข้อมูลระบบ, **Then** แถบผลลัพธ์แสดงสถานะไม่พบสินค้า (สีส้ม/แดง), แสดงเฉพาะเลขบาร์โค้ดที่อ่านได้ และไม่แสดงราคาหรือชื่อสินค้า
2. **Given** หน้าต่างกล้องสแกนเปิดอยู่, **When** สแกนไม่พบสินค้า, **Then** ระบบยังคงเปิดกล้องทำงานต่อเนื่อง (Continuous Scanning) เพื่อให้สแกนชิ้นถัดไปได้ทันที

### User Story 3 - การแสดงผลตัวอักษรและราคาตามมาตรฐาน Elderly-Friendly (Priority: P2)

ในฐานะแคชเชียร์ผู้สูงอายุ ฉันต้องการให้ข้อมูลชื่อสินค้า เลขบาร์โค้ด และราคาสินค้า มีขนาดตัวอักษรที่เด่นชัด ตัวเลขราคาเน้น Badge สีที่ตัดกับพื้นหลังและสัญลักษณ์เงินบาทที่สะดุดตา เพื่อให้อ่านง่ายในทุกสภาพแสง

**Why this priority**: สอดคล้องกับธรรมนูญระบบ (Elderly-Friendly UI/UX) ช่วยให้ผู้ปฏิบัติงานทุกวัยใช้งานได้สะดวกสบายและลดความเมื่อยล้าทางสายตา

**Independent Test**: ตรวจสอบขนาดตัวอักษร Contrast สี และการจัดวางข้อมูลบนแถบผลลัพธ์การสแกน ให้เป็นไปตามมาตรฐาน WCAG 2.1 AA

**Acceptance Scenarios**:

1. **Given** แถบผลลัพธ์การสแกนแสดงข้อมูลสินค้า, **When** แสดงราคา, **Then** ราคาต้องแสดงในรูปแบบ Badge พร้อมสัญลักษณ์เงินบาทและทศนิยม 2 ตำแหน่ง (`฿XX.XX`) มีขนาดตัวอักษรที่อ่านง่าย
2. **Given** การแสดงผลบนหน้าจออุปกรณ์ขนาดเล็ก (มือถือ/แท็บเล็ต), **When** ชื่อสินค้ายาว, **Then** ข้อความตัดบรรทัดหรือย่ออย่างเหมาะสมโดยไม่ทำให้ Badge ราคาและเลขบาร์โค้ดถูกบดบัง

---

### Edge Cases

- **สินค้าไม่มีการกำหนดราคาหรือราคาเป็น 0 บาท**: ระบบต้องแสดงราคาเป็น `฿0.00` อย่างชัดเจนโดยไม่เว้นว่าง
- **สินค้าขายตามน้ำหนัก (BY_WEIGHT)**: แสดงราคาต่อหน่วยตามที่กำหนดไว้ในข้อมูลสินค้า
- **ชื่อสินค้ายาวมาก**: จัดการแสดงผลให้ชื่อสินค้าตัดคำด้วย ellipsis และคง Badge ราคาให้แสดงอยู่เสมอ
- **การพิมพ์รหัสด้วยตนเอง (Manual Input) ที่มีช่องว่างหน้า/หลัง**: ระบบต้องตัด whitespace ออกก่อนค้นหาและแสดงผล

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: แถบแสดงผลการสแกนล่าสุด (Recent Scan Feedback) บน Modal สแกนสินค้า ต้องแสดงข้อมูลเมื่อพบสินค้า ประกอบด้วย 3 องค์ประกอบหลัก:
  1. เลขบาร์โค้ด (Barcode) ในฟอนต์ Monospace ที่อ่านง่าย
  2. ชื่อสินค้า (Product Name)
  3. ราคาขาย (Price) ในรูปแบบ Badge ป้ายราคาเด่นชัด (เช่น `฿35.00` ตัวหนา) วางข้างชื่อสินค้า
- **FR-002**: เมื่อตรวจพบบาร์โค้ดแต่ไม่พบสินค้าในระบบ แถบแสดงผลการสแกนล่าสุดต้องแสดงเฉพาะเลขบาร์โค้ดที่สแกนพบ พร้อมระบุข้อความ "ไม่พบสินค้าในระบบ" โดยต้องไม่แสดงข้อมูลราคาหรือชื่อสินค้า
- **FR-003**: ข้อมูลผลลัพธ์การค้นหาบาร์โค้ด `BarcodeScanResult` และสถานะการสแกนล่าสุด `ScanFeedbackResult` ต้องมีฟิลด์สำหรับราคา (`price?: number`) เพื่อส่งต่อจากกระบวนการค้นหามายังส่วนแสดงผล
- **FR-004**: การจัดรูปแบบราคาขายต้องแสดงเป็นสกุลเงินบาทพร้อมทศนิยม 2 ตำแหน่ง (เช่น `฿35.00`) โดยใช้ Badge สไตล์เด่นชัดตามหลักการ Elderly-Friendly
- **FR-005**: ทั้งการสแกนผ่านกล้องและการป้อนรหัสบาร์โค้ดด้วยตนเองในหน้าต่างเดียวกัน ต้องใช้ตรรกะการแสดงผลข้อมูลสินค้าและราคาในรูปแบบเดียวกัน
- **FR-006**: ระบบตัวนับสแกนสำเร็จและสแกนไม่สำเร็จ รวมถึงการทำงานแบบสแกนต่อเนื่อง (Continuous Scanning) ต้องทำงานร่วมกับการแสดงข้อมูลสินค้าได้อย่างราบรื่น
- **FR-007**: เมื่อสแกนผ่านเครื่องสแกนฮาร์ดแวร์บนหน้าจอขาย POS กล่องข้อความแจ้งเตือน Toast ต้องแสดงชื่อสินค้าพร้อมระบุราคาขาย เช่น `"ชื่อสินค้า (฿XX.XX)"` เพื่อให้ข้อมูลสอดคล้องกันทุกช่องทาง

### Key Entities

- **BarcodeScanResult**:
  - `success: boolean` (สถานะการค้นหาพบหรือไม่พบ)
  - `productName?: string` (ชื่อสินค้าที่ค้นพบ)
  - `price?: number` (ราคาขายต่อหน่วยของสินค้า)
- **ScanFeedbackResult**:
  - `status: 'SUCCESS' | 'NOT_FOUND'` (สถานะการสแกน)
  - `barcode: string` (เลขบาร์โค้ด)
  - `productName?: string` (ชื่อสินค้า กรณีพบ)
  - `price?: number` (ราคาขาย กรณีพบ)
  - `timestamp: number` (เวลาที่สแกน)

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% ของรายการสินค้าที่สแกนพบ จะแสดงข้อมูลครบทั้ง 3 รายการ (เลขบาร์โค้ด, ชื่อสินค้า, Badge ราคาขาย)
- **SC-002**: 100% ของบาร์โค้ดที่สแกนไม่พบในระบบ จะแสดงเฉพาะเลขบาร์โค้ดพร้อมสถานะแจ้งเตือน ไม่มีการแสดงราคาหรือชื่อสินค้า
- **SC-003**: ราคาที่แสดงบนแถบผลลัพธ์การสแกนและ Toast notification ตรงกับราคาของสินค้าในฐานข้อมูล 100%
- **SC-004**: แคชเชียร์สามารถรับรู้ข้อมูลสินค้าและราคาได้ทันทีภายใน 0.3 วินาทีหลังจากตรวจพบบาร์โค้ด

## Assumptions

- ข้อมูลสินค้าในแคชท้องถิ่นและที่ดึงผ่าน API มีฟิลด์ราคาขาย (`price`) พร้อมใช้งานอยู่แล้ว
- รูปแบบสกุลเงินเป็นเงินบาท (THB) เสมอ
- หากราคาสินค้าเป็นจำนวนเต็ม เช่น 20 บาท การแสดงผลจะจัดรูปแบบเป็น `฿20.00` เพื่อความสม่ำเสมอ
