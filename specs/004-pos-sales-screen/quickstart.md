# Quickstart & Verification Guide: ระบบจุดขายสินค้าหน้าร้าน (POS Sales Screen & Barcode Scanning)

**Feature Branch**: `004-pos-sales-screen`  
**Date**: 2026-10-21  

---

## 1. การเตรียมสภาพแวดล้อม (Prerequisites & Setup)

1. รัน Development Server:
   ```bash
   npm run dev
   ```
2. เปิดเบราว์เซอร์ไปยัง `http://localhost:3000`
3. เข้าสู่ระบบด้วย PIN หรือ Username/Password แคชเชียร์
4. เข้าสู่หน้าจอขายหน้าร้านที่ URL: `http://localhost:3000/pos`

---

## 2. ขั้นตอนการทดสอบการใช้งานจริง (Validation Scenarios)

### Scenario 1: การเลือกสินค้าด้วยตนเองและเพิ่มลงตะกร้า (Manual Selection)
1. ตรวจสอบว่าแผงสินค้าด้านซ้าย (Product Grid) แสดงการ์ดสินค้าขนาดใหญ่ พร้อมรูปภาพ ชื่อ และราคา (บาท)
2. แตะปุ่มหมวดหมู่สินค้าด้านบน (Category Tabs) ตรวจสอบว่ารายการสินค้ากรองตามหมวดหมู่ทันที
3. พิมพ์คำค้นหาในช่องค้นหาด่วน (เช่น "น้ำ") ตรวจสอบว่าแสดงผลสินค้าที่ตรงกับคำค้นหา
4. แตะที่การ์ดสินค้า 1 ครั้ง:
   - ตรวจสอบว่าสินค้าปรากฏในแถบตะกร้าสินค้าด้านขวา (Cart Panel) จำนวน 1 ชิ้น
   - ตรวจสอบว่าได้ยินเสียง Beep สั้นโทนสูง (Success Audio Tone)
5. แตะที่การ์ดสินค้าเดิมซ้ำอีกครั้ง:
   - ตรวจสอบว่าจำนวนสินค้าเพิ่มเป็น 2 ชิ้น และยอดเงินรวมในตะกร้าคำนวณเพิ่มขึ้นทันที

### Scenario 2: การสแกนบาร์โค้ดด้วยเครื่องสแกนฮาร์ดแวร์ (Hardware Scanner Emulation)
1. อยู่ที่หน้าจอ POS โดยไม่ต้องคลิกเมาส์ที่ช่อง Input ใดๆ
2. ใช้เครื่องสแกนบาร์โค้ดยิงบาร์โค้ดสินค้าจริง (หรือจำลองการพิมพ์รหัสตัวเลขแล้วกด Enter อย่างรวดเร็ว)
3. ตรวจสอบว่าระบบตรวจพบรหัสทันที ดึงข้อมูลสินค้า และเพิ่มลงในตะกร้าพร้อมเสียง Beep
4. ทดสอบเปลี่ยนแป้นพิมพ์ของระบบปฏิบัติการเป็น **ภาษาไทย** แล้วลองยิงบาร์โค้ด:
   - ตรวจสอบว่าระบบมีระบบ Thai-to-English Key Mapping สามารถถอดรหัสบาร์โค้ดและเพิ่มสินค้าได้ถูกต้อง 100%

### Scenario 3: การสแกนบาร์โค้ดด้วยกล้องอุปกรณ์ (Camera Barcode Scanner)
1. แตะปุ่ม "สแกนด้วยกล้อง" (ไอคอนกล้องขนาดใหญ่ >= 48px)
2. ยอมรับสิทธิ์การเข้าถึงกล้อง (Camera Permission)
3. ตรวจสอบว่าปรากฏหน้าต่าง Modal ขนาดใหญ่ตรงกลางจอ พร้อมกรอบเล็งสแกน (Viewfinder) และปุ่มสลับกล้อง
4. นำสินค้าที่มีบาร์โค้ดมาส่องในกรอบเล็ง:
   - ตรวจสอบว่าเมื่อกล้องอ่านบาร์โค้ดได้ จะมีเสียง Beep ดังขึ้น 1 ครั้ง
   - สินค้าถูกเพิ่มลงในตะกร้า และกล้องยังคงเปิดรอสแกนชิ้นถัดไปได้ทันที (Continuous Scan Mode)
5. แตะปุ่ม "เสร็จสิ้น / ปิดกล้อง" เพื่อปิดหน้าต่างกล้อง

### Scenario 4: การแจ้งเตือนกรณีสแกนไม่พบบาร์โค้ด (Error Handling)
1. ยิงบาร์โค้ดที่ไม่มีอยู่ในระบบ เช่น `9999999999999`
2. ตรวจสอบว่าได้ยินเสียงเตือนข้อผิดพลาด (Error Buzzer โทนเสียงต่ำ แตกต่างจากเสียง Beep ชัดเจน)
3. ตรวจสอบว่ามีแบนเนอร์แจ้งเตือน Toast สีแดงเด่นชัดขึ้นที่หน้าจอว่า "ไม่พบบาร์โค้ด [9999999999999] ในระบบ"
4. ตรวจสอบว่าไม่มี Modal เด้งมาบล็อกหน้าจอ และสามารถสแกนสินค้าชิ้นถัดไปต่อได้ทันที

### Scenario 5: การปรับจำนวนสินค้าและแป้นพิมพ์สัมผัส (Virtual Numpad)
1. ในแถบตะกร้าสินค้าด้านขวา กดปุ่มเครื่องหมายบวก (+) และ ลบ (-)
2. แตะที่ตัวเลขจำนวนสินค้าเพื่อเปิดแป้นพิมพ์ตัวเลขสัมผัส (Virtual Numeric Keypad)
3. พิมพ์จำนวนใหม่ เช่น "12" แล้วกดยืนยัน ตรวจสอบว่าจำนวนและยอดเงินรวมคำนวณใหม่ถูกต้อง
4. กดปุ่มลบ (ไอคอนถังขยะ) เพื่อลบสินค้านั้นออกจากตะกร้า
5. กดปุ่ม "ล้างตะกร้า / ยกเลิกบิล" ตรวจสอบว่ามีกล่องยืนยันขนาดใหญ่ขึ้นมาถามความแน่ใจ เมื่อกดยืนยัน ตะกร้าจะว่างเปล่า

### Scenario 6: การตรวจสอบสถานะกะขายและเงื่อนไขการชำระเงิน (Active Shift Gate)
1. หากสาขายังไม่ได้เปิดกะ ตรวจสอบว่ามีแถบเตือนสีส้มด้านบนว่า "ยังไม่ได้เปิดกะขาย"
2. ทดลองเลือกสินค้าใส่ตะกร้า (ทำได้ตามปกติ)
3. กดปุ่ม "ดำเนินการชำระเงิน" (Checkout):
   - ตรวจสอบว่าระบบเปิด Modal "เปิดกะการขาย" บังคับให้ป้อนเงินทอนเริ่มต้นก่อน จึงจะดำเนินการต่อไปได้
