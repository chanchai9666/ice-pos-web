# Data Model: การปรับปรุงระบบพิสูจน์ตัวตนแบบผสมผสาน (Hybrid Authentication Support)

**Branch**: `009-hybrid-auth-support`  
**Feature**: `specs/009-hybrid-auth-support/spec.md`  

## Entities

### 1. RequestOptions (การตั้งค่าคำขอส่งข้อมูลผ่านเครือข่าย)

ตัวเลือกการส่งคำขอระดับระบบที่ควบคุมการแนบข้อมูลรับรองความปลอดภัยและการจัดการ Header

| ฟิลด์ | ชนิดข้อมูล | บังคับ | คำอธิบาย |
|---|---|---|---|
| `credentials` | `'include' \| 'same-origin' \| 'omit'` | ไม่บังคับ (ค่าเริ่มต้น `'include'`) | กำหนดการส่งผ่านคุกกี้ข้าม Origin |
| `headers` | `Record<string, string> \| Headers` | ไม่บังคับ | ส่วนหัวของคำขอ HTTP |
| `params` | `Record<string, string \| number \| boolean \| undefined>` | ไม่บังคับ | พารามิเตอร์ Query String |
| `_isRetry` | `boolean` | ไม่บังคับ | ตัวบ่งชี้ว่าเป็นคำขอที่ส่งซ้ำหลังต่ออายุสิทธิ์หรือไม่ |

---

### 2. SessionState (สถานะการเข้าสู่ระบบของผู้ใช้งาน)

ข้อมูลบริบทของเซสชันที่ถูกใช้งานในส่วนต่างๆ ของแอปพลิเคชันผ่าน `AuthContext`

| ฟิลด์ | ชนิดข้อมูล | บังคับ | คำอธิบาย |
|---|---|---|---|
| `user` | `UserProfile \| null` | ใช่ | ข้อมูลโปรไฟล์ของผู้ใช้งานที่เข้าสู่ระบบ |
| `branch` | `Branch \| null` | ใช่ | สาขาปัจจุบันที่ผู้ใช้กำลังปฏิบัติงาน |
| `isAuthenticated` | `boolean` | ใช่ | ค่าระบุว่ามีผู้ใช้งานเข้าสู่ระบบอยู่หรือไม่ (`!!user`) |
| `isLoading` | `boolean` | ใช่ | สถานะการโหลดข้อมูลเซสชันเบื้องต้น |

---

### 3. SessionLifecycleEvent (เหตุการณ์วงจรชีวิตของเซสชัน)

ข้อมูลเหตุการณ์การเปลี่ยนแปลงสถานะของเซสชันที่ส่งผ่าน `registerSessionExpiredListener`

| ฟิลด์ | ชนิดข้อมูล | บังคับ | คำอธิบาย |
|---|---|---|---|
| `type` | `'SESSION_EXPIRED' \| 'LOGOUT' \| 'UNAUTHORIZED'` | ใช่ | ชนิดของเหตุการณ์ที่เกิดขึ้น |
| `message` | `string` | ใช่ | ข้อความแจ้งเตือนภาษาไทยที่กระชับและเข้าใจง่าย |
| `timestamp` | `number` | ใช่ | เวลาที่เกิดเหตุการณ์ (มิลลิวินาที) |

---

### 4. CashierContinuityContext (ข้อมูลบริบทการทำงานต่อเนื่องของแคชเชียร์)

ข้อมูลที่ต้องคงไว้ในหน่วยความจำของอุปกรณ์ (LocalStorage) แม้เซสชันจะหมดอายุ เพื่อให้แคชเชียร์สลับกะหรือล็อกอิน PIN กลับมาทำงานต่อได้ทันที

| ข้อมูล | คีย์จัดเก็บ | วัตถุประสงค์ |
|---|---|---|
| สาขาปัจจุบัน | `ice_pos_current_branch` | คงสาขาเดิมไว้ ไม่ต้องเลือกใหม่เมื่อเซสชันหมดอายุ |
| รหัสสาขาล่าสุด | `ice_pos_last_branch_id` | ใช้แสดงผลในหน้า PIN Login |
| ตะกร้าสินค้าหน้าร้าน | `ice_pos_cart` (หรือ cart state) | คงรายการสินค้าที่ยิงบาร์โค้ดไว้ ไม่ต้องเริ่มคิดเงินใหม่ |

       │                                         │            │
