# Feature Specification: การแสดงจำนวนสินค้าคงเหลือ/ชั่งขาย และปรับปรุงตะกร้าสินค้า POS (POS Stock Level Display & Cart UX Enhancements)

**Feature Branch**: `006-pos-stock-and-cart`

**Created**: 2026-10-24

**Status**: Draft

**Input**: User description: "-เพิ่มแสดงจำนวนสินค้าคงเหลือ ,หากสินค้าขายตามน้ำหนัก ให้แสดงเป็น ชั่งขาย -ตระกล้าสินค้าให้แสดงรูปภาพขนาดเล็ก และเมื่อมีการเพิ่มสินค้าให้แสดงสินค้าล่าสุดไม่ค้างอยู่ด้านบน"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - การแสดงจำนวนสินค้าคงเหลือและการระบุสินค้าชั่งขายบนการ์ดสินค้า (Stock Level & Weight-Based Indicator on Product Cards) (Priority: P1)

แคชเชียร์สามารถมองเห็นสถานะสต็อกของสินค้าแต่ละรายการบนการ์ดสินค้าในหน้าจอ POS ได้อย่างชัดเจน โดยสินค้าทั่วไปที่คิดราคาตามจำนวนชิ้น/หน่วย (PRICE_PER_UNIT) จะแสดงจำนวนสินค้าคงเหลือในคลังสาขาปัจจุบัน เพื่อให้แคชเชียร์ทราบทันทีว่ามีสินค้าพร้อมขายหรือไม่ ส่วนสินค้าประเภทที่ขายตามน้ำหนัก (BY_WEIGHT) จะแสดงข้อความว่า "ชั่งขาย" อย่างเด่นชัดแทนการแสดงจำนวนชิ้น

**Why this priority**: การแสดงสต็อกคงเหลือช่วยป้องกันไม่ให้แคชเชียร์คิดเงินสินค้าที่สต็อกหมด และการระบุ "ชั่งขาย" ทำให้แคชเชียร์ทราบทันทีว่าสินค้านี้ต้องนำไปชั่งน้ำหนักก่อนคิดเงิน ช่วยลดข้อผิดพลาดในการขายหน้าร้าน

**Independent Test**: เข้าสู่หน้าจอขาย POS แล้วตรวจสอบการ์ดสินค้าแต่ละรายการ: สินค้าขายตามหน่วยต้องแสดงจำนวนสต็อกคงเหลือที่สอดคล้องกับคลังสาขา และสินค้าขายตามน้ำหนักต้องแสดงป้าย "ชั่งขาย" อย่างชัดเจน

**Acceptance Scenarios**:

1. **Given** แคชเชียร์อยู่ที่หน้าจอ POS และระบบโหลดข้อมูลสินค้าและสต็อกสาขาสำเร็จ, **When** ดูการ์ดสินค้าที่เป็นประเภทขายตามหน่วย (PRICE_PER_UNIT), **Then** การ์ดแสดงป้ายจำนวนคงเหลือ เช่น "คงเหลือ: 15 ชิ้น" ด้วยตัวอักษรและสีที่อ่านง่าย คอนทราสต์สูง
2. **Given** มีสินค้าที่ขายตามหน่วยและสต็อกในสาขาเท่ากับ 0 (สินค้าหมด), **When** แคชเชียร์ดูการ์ดสินค้านั้น, **Then** ระบบแสดงสถานะ "สินค้าหมด" (Out of Stock) ด้วยป้ายเตือนสีชัดเจน เพื่อให้แคชเชียร์ทราบก่อนกดเลือก
3. **Given** แคชเชียร์ดูสินค้าที่เป็นประเภทขายตามน้ำหนัก (BY_WEIGHT), **When** การ์ดแสดงผลบนหน้าจอ, **Then** ระบบแสดงข้อความ "ชั่งขาย" เป็นป้ายสถานะเด่นชัดบนการ์ดสินค้า แทนการแสดงจำนวนชิ้น
4. **Given** แคชเชียร์เลือกเปลี่ยนสาขาการขาย, **When** สาขาเปลี่ยนไป, **Then** จำนวนสต็อกคงเหลือของสินค้าจะอัปเดตให้ตรงกับยอดสต็อกของสาขาใหม่นั้น

### User Story 2 - การแสดงรูปภาพขนาดเล็กในแต่ละรายการของตะกร้าสินค้า (Small Product Thumbnail in Cart Items) (Priority: P1)

แคชเชียร์สามารถตรวจสอบรายการสินค้าในตะกร้าขาย (Cart) ได้อย่างรวดเร็วและมั่นใจผ่านรูปภาพตัวอย่างขนาดเล็ก (Thumbnail) ที่ปรากฏคู่กับชื่อสินค้า ราคา และจำนวน ในแต่ละแถวของตะกร้าสินค้า

**Why this priority**: การมีรูปภาพประกอบขนาดกะทัดรัดในตะกร้าช่วยให้แคชเชียร์สามารถกวาดสายตาตรวจสอบความถูกต้องของสินค้าในบิลได้อย่างรวดเร็ว ลดความผิดพลาดในการยิงบาร์โค้ดผิดรายการ และสอดคล้องกับมาตรฐานการใช้งานง่ายสำหรับผู้สูงอายุ (Elderly-Friendly)

**Independent Test**: เพิ่มสินค้าที่มีรูปภาพและไม่มีรูปภาพลงในตะกร้าขาย แล้วตรวจดูแถวรายการสินค้าในตะกร้าว่ามีรูปภาพขนาดย่อมแสดงอย่างถูกต้อง สวยงาม และไม่บดบังปุ่มปรับจำนวนหรือราคา

**Acceptance Scenarios**:

1. **Given** แคชเชียร์เพิ่มสินค้าที่มีรูปภาพลงในตะกร้า, **When** รายการสินค้าปรากฏในแผงตะกร้า, **Then** แถวรายการแสดงรูปภาพสินค้าขนาดเล็ก (Thumbnail ขอบมน ชัดเจน) เคียงข้างชื่อสินค้า
2. **Given** แคชเชียร์เพิ่มสินค้าที่ไม่มีรูปภาพ หรือรูปภาพไม่สามารถโหลดได้, **When** รายการสินค้าแสดงในตะกร้า, **Then** ระบบแสดงไอคอนตัวแทนสินค้า (Fallback Icon) ในกรอบขนาดเดียวกันอย่างกลมกลืนและเรียบร้อย
3. **Given** รายการแสดงรูปภาพขนาดเล็ก, **When** ดูการจัดวางองค์ประกอบบนหน้าจอ, **Then** ปุ่มกดปรับจำนวน (+/-) ปุ่มเปิดแป้นตัวเลข และปุ่มลบ ยังคงรักษาขนาดเป้าหมายสัมผัสที่ใหญ่ (Touch Target อย่างน้อย 48x48px) ตามมาตรฐาน Elderly-Friendly

### User Story 3 - การเลื่อนแสดงสินค้าล่าสุดในตะกร้าอัตโนมัติ ไม่ค้างอยู่ด้านบน (Auto-Scroll & Focus on Latest Added Cart Item) (Priority: P1)

เมื่อแคชเชียร์ทำการเพิ่มสินค้าใหม่ลงในบิล หรือสแกนบาร์โค้ด/กดเพิ่มจำนวนสินค้าเดิม แผงตะกร้าสินค้าจะทำการเลื่อนมุมมอง (Scroll) ไปยังตำแหน่งของสินค้าล่าสุดที่เพิ่งทำรายการโดยอัตโนมัติ พร้อมแสดงเอฟเฟกต์เน้นรายการล่าสุด (Visual Highlight) ทำให้แคชเชียร์มองเห็นรายการที่เพิ่งเพิ่มได้ทันที ไม่ถูกบดบังหรือค้างอยู่ที่ส่วนบนสุดของตะกร้า

**Why this priority**: เมื่อมีรายการสินค้าในบิลหลายรายการจนล้นความสูงของแผงตะกร้า การที่หน้าจอค้างอยู่ที่เดิมหรือด้านบนทำให้แคชเชียร์มองไม่เห็นว่าสินค้าที่เพิ่งสแกนเพิ่มเข้ามาถูกบันทึกจริงหรือไม่ การเลื่อนอัตโนมัติพร้อมไฮไลต์ช่วยสร้างความมั่นใจในการขายและความต่อเนื่องในการทำงาน

**Independent Test**: เพิ่มสินค้าลงในตะกร้าจนเกิดแถบเลื่อน (Scrollbar) จากนั้นเพิ่มสินค้าชิ้นใหม่หรือสแกนสินค้าเดิม ตรวจสอบว่าแผงตะกร้าเลื่อนไปยังตำแหน่งสินค้าที่เพิ่งเพิ่มหรือปรับปรุงโดยอัตโนมัติ พร้อมไฮไลต์ชั่วคราว

**Acceptance Scenarios**:

1. **Given** ในตะกร้ามีรายการสินค้าจำนวนมากจนเกิดการเลื่อนในแนวตั้ง (Vertical Scroll), **When** แคชเชียร์สแกนหรือกดเพิ่มสินค้าใหม่, **Then** แผงตะกร้าเลื่อนมุมมอง (Smooth Scroll) ไปยังตำแหน่งสินค้าใหม่ทันที โดยสินค้าใหม่ไม่ตกขอบหน้าจอ
2. **Given** แคชเชียร์กดเพิ่มสินค้าเดิมที่มีอยู่ในตะกร้าแล้ว (ซึ่งอยู่ล่างหรืออยู่นอกพื้นที่มุมมองปัจจุบัน), **When** จำนวนสินค้าได้รับการปรับเพิ่ม, **Then** แผงตะกร้าเลื่อนมุมมองไปยังแถวสินค้านั้น พร้อมแสดงเอฟเฟกต์สีไฮไลต์ชั่วคราว (เช่น แฟลชสีฟ้า/เขียว 1-2 วินาที)
3. **Given** มีการล้างบิลหรือลบรายการสินค้า, **When** ดำเนินการเสร็จสิ้น, **Then** แผงตะกร้าปรับตำแหน่งการแสดงผลอย่างถูกต้องและราบรื่น

---

### Edge Cases

- **กรณีเครือข่ายขัดข้องหรือไม่สามารถดึงยอดสต็อกจาก API ได้**: การ์ดสินค้าต้องแสดงสถานะสำรอง เช่น ไม่แสดงตัวเลขสต็อก หรือแสดงป้าย "สต็อก: -" โดยไม่ทำให้หน้าจอพังหรือขัดขวางการเลือกขายสินค้า
- **กรณีสินค้าขายตามน้ำหนักมีข้อมูลสต็อกในคลังเป็นทศนิยม**: บนการ์ดสินค้าของ POS ยังคงแสดงป้าย "ชั่งขาย" เป็นหลัก เพื่อความกระชับและชัดเจนในการปฏิบัติงานของแคชเชียร์
- **กรณีสแกนสินค้าติดต่อกันอย่างรวดเร็ว (Rapid Consecutive Scanning)**: การเลื่อนมุมมอง (Auto-scroll) ต้องไม่หน่วง กระตุก หรือขัดจังหวะการรับข้อมูลบาร์โค้ดชิ้นต่อไป
- **กรณีชื่อสินค้ายาวมากร่วมกับการแสดงรูปภาพขนาดเล็กในตะกร้า**: ข้อความชื่อสินค้าต้องตัดขึ้นบรรทัดใหม่อย่างเหมาะสม หรือตัดท้ายด้วยจุดไข่ปลา (Truncate/Line-clamp) โดยไม่เบียดบังรูปภาพหรือปุ่มลบรายการ

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ระบบต้องดึงข้อมูลสต็อกคงเหลือของสินค้าในสาขาปัจจุบันจากระบบคลังสินค้า และนำมาแสดงผลบนการ์ดสินค้าในหน้าจอ POS
- **FR-002**: สำหรับสินค้าประเภทคิดราคาต่อหน่วย (PRICE_PER_UNIT) การ์ดสินค้าต้องแสดงจำนวนคงเหลือจริงพร้อมหน่วยนับ เช่น "คงเหลือ: 10 ชิ้น"
- **FR-003**: หากสินค้าประเภทคิดราคาต่อหน่วยมีจำนวนคงเหลือเท่ากับ 0 หรือน้อยกว่า 0 ระบบต้องแสดงป้ายกำกับ "สินค้าหมด" และปรับโทนสีการ์ดให้เห็นชัดเจน
- **FR-004**: สำหรับสินค้าประเภทคิดราคาตามน้ำหนัก (BY_WEIGHT) การ์ดสินค้าต้องแสดงป้ายระบุว่า "ชั่งขาย" อย่างชัดเจนแทนการแสดงจำนวนคงเหลือเป็นชิ้น
- **FR-005**: ในแต่ละแถวของรายการสินค้าในตะกร้า (Cart Item Row) ต้องแสดงรูปภาพสินค้าขนาดเล็ก (Thumbnail) ขนาดอย่างน้อย 40x40px ถึง 48x48px
- **FR-006**: กรณีที่สินค้าไม่มีรูปภาพ หรือรูปภาพไม่สามารถแสดงผลได้ แถวรายการสินค้าต้องแสดงไอคอนตัวแทนสินค้า (Fallback Icon) ที่มีขนาดและรูปแบบเข้ากันได้
- **FR-007**: เมื่อมีการเพิ่มสินค้าใหม่เข้าสู่ตะกร้า แผงรายการตะกร้าต้องเลื่อนมุมมอง (Auto-Scroll) ไปยังตำแหน่งของสินค้ารายการล่าสุดโดยอัตโนมัติ
- **FR-008**: เมื่อมีการสแกนซ้ำหรือเพิ่มจำนวนสินค้าที่มีอยู่ในตะกร้าเดิม แผงรายการตะกร้าต้องเลื่อนมุมมองไปยังตำแหน่งสินค้านั้น พร้อมแสดงสัญญาณไฮไลต์ชั่วคราว (Visual Feedback Highlight)
- **FR-009**: องค์ประกอบทั้งหมดต้องรักษามาตรฐาน Elderly-Friendly โดยมีปุ่มควบคุมขนาดสัมผัสไม่ต่ำกว่า 48x48px และมีคอนทราสต์ของสีข้อความผ่านเกณฑ์ WCAG 2.1 AA

### Key Entities *(include if feature involves data)*

- **Stock Level (ข้อมูลระดับสต็อกคงเหลือ)**: ข้อมูลปริมาณสินค้าคงคลังของแต่ละสินค้าในสาขาปัจจุบัน ประกอบด้วย `productId`, `branchId`, `quantity` (จำนวนคงเหลือจริง), `reservedQuantity` (จำนวนที่ถูกจอง)
- **Product Card Display Mode (รูปแบบการแสดงผลบนการ์ดสินค้า)**: คุณลักษณะการแสดงผลของการ์ดสินค้าที่จำแนกตามประเภทสินค้า (`PRICE_PER_UNIT` แสดงจำนวนคงเหลือ / `BY_WEIGHT` แสดงป้าย "ชั่งขาย")
- **Cart Item Visual (องค์ประกอบการแสดงผลในตะกร้า)**: ข้อมูลสำหรับแสดงผลในตะกร้า ได้แก่ รูปภาพสินค้า (Thumbnail), ชื่อสินค้า, รหัสบาร์โค้ด, ราคาต่อหน่วย, ตัวปรับจำนวน (+/-), ยอดรวม และสถานะการเป็นรายการล่าสุด (isLatest/activeHighlight)

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: แคชเชียร์สามารถทราบได้ทันทีว่าสินค้าใดเป็นสินค้าชั่งขายหรือมีสต็อกคงเหลือเท่าใด โดยใช้เวลาสังเกตไม่เกิน 1 วินาทีต่อการ์ดสินค้า
- **SC-002**: อัตราความผิดพลาดในการคิดเงินสินค้าที่สต็อกหมดหรือหยิบผิดประเภทสินค้าลดลงอย่างน้อย 80%
- **SC-003**: 100% ของรายการสินค้าในตะกร้าแสดงรูปภาพขนาดเล็กหรือไอคอนตัวแทนที่ถูกต้อง ชัดเจน โดยไม่ทำให้ความเร็วในการโหลดหรือตอบสนองช้าลง
- **SC-004**: เมื่อเพิ่มสินค้าใหม่หรือแก้ไขจำนวนสินค้าในบิล แผงตะกร้าเลื่อนแสดงสินค้าล่าสุดโดยสมบูรณ์ภายในเวลาไม่เกิน 300 มิลลิวินาที
- **SC-005**: ผู้ใช้งานทุกช่วงวัยรวมถึงผู้สูงอายุสามารถใช้งานและกดยืนยันรายการได้อย่างถูกต้องและแม่นยำ ไม่พบปัญหาการสัมผัสปุ่มผิดพลาด

## Assumptions

- ข้อมูลสต็อกสินค้าคงเหลืออ้างอิงจากสาขาที่ผู้ใช้งานกำลังปฏิบัติงานอยู่ (Active Branch) ตามที่ได้รับจากระบบสิทธิ์และกะการขาย
- สำหรับสินค้าชั่งขาย การชั่งน้ำหนักและการคิดราคาจะคำนวณตามอัตราและหน่วยนับน้ำหนัก (เช่น กิโลกรัม) ตามขั้นตอนการขายสินค้าชั่งน้ำหนัก
- ตำแหน่งของรายการสินค้าในตะกร้าจะยังคงเรียงลำดับตามการเพิ่มเข้าบิล โดยใช้วิธี Auto-Scroll เลื่อนมุมมองไปยังรายการล่าสุด เพื่อไม่ให้รบกวนลำดับรายการเดิมที่แคชเชียร์คุ้นเคย
- รูปภาพสินค้าที่แสดงในตะกร้าจะใช้ URL รูปภาพเดียวกันกับที่แสดงบนการ์ดสินค้าหลัก โดยถูกย่อขนาดแสดงผลผ่านเลย์เอาต์ Thumbnail ในฝั่งหน้าบ้าน
