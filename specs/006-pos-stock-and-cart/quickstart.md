# Quickstart & Verification Guide: การแสดงจำนวนสินค้าคงเหลือ/ชั่งขาย และปรับปรุงตะกร้าสินค้า POS

**Feature**: `006-pos-stock-and-cart`
**Date**: 2026-10-24

## วัตถุประสงค์ (Purpose)
คู่มือสำหรับตรวจสอบการทำงานของระบบหลังการพัฒนาเสร็จสมบูรณ์ ให้ครอบคลุมทุกสถานการณ์ทดสอบหลักตาม User Scenarios

---

## ขั้นตอนการเตรียมการ (Prerequisites & Setup)

1. รันระบบ Frontend ในสภาพแวดล้อม Development:
   ```bash
   npm run dev
   ```
2. เข้าสู่ระบบ POS Terminal ที่หน้า `http://localhost:3000/pos`
3. เปิดกะการขาย (Open Shift) พร้อมระบุเงินทอนเริ่มต้น

---

## สถานการณ์ทดสอบที่ 1: ตรวจสอบการแสดงสต็อกสินค้าคงเหลือและสินค้าชั่งขาย

1. **การ์ดสินค้าประเภทคิดราคาตามหน่วย (`PRICE_PER_UNIT`)**:
   - สังเกตการ์ดสินค้า เช่น "มาม่าช้างน้อย" หรือ "Default Sell UOM Product"
   - ต้องมีป้ายแสดงจำนวนคงเหลือ เช่น `คงเหลือ: 24 ชิ้น` หรือ `สต็อก: 24`
   - หากยอดสต็อกเป็น 0 ต้องแสดงป้ายสีแดง `สินค้าหมด` ชัดเจน
2. **การ์ดสินค้าประเภทขายตามน้ำหนัก (`BY_WEIGHT`)**:
   - สังเกตการ์ดสินค้า เช่น "น้ำแข็ง" หรือสินค้าที่ตั้งค่าเป็น BY_WEIGHT
   - ต้องแสดงป้ายกำกับข้อความ **`ชั่งขาย`** เด่นชัด แทนการแสดงตัวเลขจำนวนชิ้น

---

## สถานการณ์ทดสอบที่ 2: ตรวจสอบรูปภาพขนาดเล็กในตะกร้าสินค้า

1. แตะเลือกสินค้าที่มีรูปภาพ หรือยิงบาร์โค้ดลงในตะกร้า
2. สังเกตแถวรายการสินค้าในตะกร้าขวามือ ([`PosCartItemRow`](file:///Users/chanchai/workshop/CODE/ice-pos-web/src/components/pos/PosCartItemRow.tsx)):
   - มีรูปภาพขนาดเล็ก (Thumbnail ขอบมน) แสดงเคียงข้างชื่อสินค้า
   - หากสินค้าไม่มีรูปภาพ ต้องแสดงไอคอนกล่องสินค้า Fallback อย่างสวยงาม
   - ปุ่มกดลด/เพิ่ม (+/-) และปุ่มถังขยะยังคงมีขนาดสัมผัสไม่ต่ำกว่า 48x48px

---

## สถานการณ์ทดสอบที่ 3: ตรวจสอบการเลื่อนแสดงสินค้าล่าสุดในตะกร้าอัตโนมัติ

1. เลือกสินค้าใส่ตะกร้าติดต่อกัน 5-8 รายการ จนกระทั่งแผงตะกร้ามีความสูงเกินจอและเกิด Scrollbar
2. เลื่อนหน้าจอตะกร้าขึ้นไปที่ด้านบนสุด
3. กดเลือกสินค้าใหม่จากฝั่งซ้าย หรือสแกนบาร์โค้ดสินค้าชิ้นใหม่:
   - แผงตะกร้าต้องทำ Smooth Scroll เลื่อนลงมายังรายการสินค้าล่าสุดโดยอัตโนมัติ
   - หน้าจอไม่ค้างอยู่ด้านบน
   - รายการสินค้าล่าสุดแสดงเอฟเฟกต์ไฮไลต์สีฟ้า/เขียวชั่วคราว (Highlight Flash) เพื่อดึงดูดสายตา
4. ทดสอบกดเพิ่มจำนวน (+) ในสินค้าที่มีอยู่แล้ว แผงตะกร้าต้องเลื่อนไปยังตำแหน่งสินค้านั้นพร้อมไฮไลต์เช่นเดียวกัน
